# Programming for Web Development – I Laboratory

## About This Repository

This repository contains all 13 practical assignments completed as part of the Programming for Web Development – I Laboratory.

The practicals cover terminal navigation, Git and GitHub, HTML, CSS, Flexbox, CSS Grid, and responsive web design.

- JavaScript
- Git

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the required practical folder.
4. Open its `index.html` file.
5. Run it using Live Server or open it in a web browser.
